# PANDAO 网页批量查询

把网页里一次查询的读取请求，变成参数表驱动的批量任务。自动翻页、保存进度、有限重试，输出表格和中文结论。

例如在目录网站上按类别查资料：先在网页完成一次查询，导出浏览记录，再把要查的类别填进参数表。本工具直接读取对应数据，逐页保存，不需要每个类别重新点页面。

- [源码](https://github.com/tianchaodaxing-beep/pandao-request-batch)
- [下载 0.1.0](https://github.com/tianchaodaxing-beep/pandao-request-batch/releases/download/v0.1.0/pandao-request-batch-v0.1.0.zip)
- [版本说明](https://github.com/tianchaodaxing-beep/pandao-request-batch/releases/tag/v0.1.0)

需要 Python 3.11 或更高版本。解压后，Windows 双击 `打开网页批量查询.cmd`。其他系统在项目目录运行：

```sh
python -m pip install .
python -m pandao_batch serve --open
```

页面仅在本机运行。运行依赖是 Python 标准库，不需要模型或付费接口；安装构建使用 setuptools。

点击“载入模拟演示”，再点击“开始批量查询”，可以体验 12 项查询的完整过程。演示是本机模拟数据，不代表真实客户或商业效果。

## 使用自己的网页查询

1. 在浏览器打开你有权读取的网站，按 F12 进入开发者工具，打开 Network（网络），完成一次正常查询。
2. 导出包含响应内容的 HAR 浏览记录。浏览器菜单可能显示 Save all as HAR with content（保存所有包含内容的浏览记录），具体名称随版本变化。
3. 在本工具导入文件，选择读取来源、记录位置、来源总量、翻页选项和唯一编号。
4. 导入或填写 CSV 参数表。列名需与捕获请求的查询参数一致；一行代表一组查询条件。翻页列由工具控制，不放进参数表。
5. 开始运行，完成后下载结果包。失败时已有结果保留，可处理错误后续跑。

HAR 与本机读取配置可能包含登录信息，**不要上传公开仓库或发送给别人**。浏览器默认导出可能不含登录信息；需要登录的读取请求必须在本机拥有有效的登录头或 Cookie。工具不会替你登录、刷新动态签名、解决验证码或绕过站点访问限制。

## 适用范围

支持 HAR 中已捕获的 GET 请求，其响应需要是 JSON，并包含对象记录数组。支持普通按页码递增的分页；可选指定来源返回的总量及记录唯一编号。

暂不支持只用 POST 查询、游标分页、依赖实时动态签名的请求，或必须在浏览器内执行才能读取的网站。不能从一次捕获推断整个网站的业务规则。GET 也可能被个别网站用于实际动作，请只选择确实读取数据的来源。

适合目录查询、公开资料检索、内部系统已有权限的数据导出等场景；是否能读取取决于实际站点。首版只在本机模拟服务上完成任务实测，没有用户真实站点验收。

## 断点与数据核对

- 每页读取并检查后保存；临时网络故障或限流最多重试两次，次数可配置。
- 同一配置、登录信息、参数表和起始页可以续跑。更换其中任一项时，需要新结果目录。
- 每项查询分别去重；指定唯一编号时按编号，否则按整条记录内容。不同查询之间保留各自结果。
- 来源提供总量时逐项核对；翻页期间总量变化、重复页面、记录结构变化、数量不一致都会停止，不能报告读完。
- 没有来源总量时，读到空页才结束；达到页数上限仍有数据会停止。单页查询只能证明这一页已读取。
- 已保存页面的内容与断点记录核对后，生成 CSV、JSONL，再独立读取两种导出文件核对条数。

来源总量与条数相同并不能证明记录没有在翻页过程中被替换；需要稳定数据或站点提供快照能力。工具记录采集时间；来源没有提供数据更新时间时如实注明，不能将采集时间当作业务数据截止日期。

结果不是脱敏文件。CSV 是 UTF-8 编码，便于 Excel 打开；JSONL 保留嵌套结构。每条记录带查询序号和页码，便于追溯。

## 命令行与重复运行

先查看可用读取来源，输出中的登录参数会隐藏：

```sh
python -m pandao_batch inspect "浏览记录.har"
```

保存本机配置。`--entry` 使用上一步实际来源序号；以下序号和位置只是说明格式：

```sh
python -m pandao_batch prepare "浏览记录.har" --entry 0 --out "读取配置.json" --records-pointer "/data/items" --total-pointer "/data/total" --page-param "page" --id-field "id"
python -m pandao_batch run "读取配置.json" "查询参数.csv" --out "查询结果"
```

续跑不覆盖已登记的页面；可以增加页数或记录限额：

```sh
python -m pandao_batch run "读取配置.json" "查询参数.csv" --out "查询结果" --resume --max-pages 200
```

其他参数：`--interval 0.2`、`--retries 2`、`--timeout 15`、`--max-seconds 600`、`--max-records 100000`。每次运行结束保存中文结论，适合接入已有任务工具，不需要 AI 逐页操作。

模拟完整任务：

```sh
python 运行模拟演示.py
```
